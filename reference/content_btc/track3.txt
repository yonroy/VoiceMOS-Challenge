Track 3: Predicting MOS of speaker and accent similarity for codec-based speech synthesis systems
Task & dataset description
The objective of this track is to predict the mean opinion score (MOS) of speaker and accent similarity for neural audio codec (NAC)-based speech synthesis systems. Given an input speech sample and a reference speech sample, the system is required to predict both the speaker and accent similarity scores, ranging from one to five.

This track is based on the CodecMOS-Accent dataset. [arXiv paper link]

This dataset is based on the VCTK dataset. It contains two types of samples: first, resynthesis samples were generated by encoding the input speech sample into a compressed representation, and subsequently decoding it back into waveform. Second, voice-cloned text-to-speech (TTS) samples were generated by inputting an input text and a reference audio sample to an NAC-based TTS sample, such that the generated speech accurately articulates the target text while preserving both the speaker identity and accent present in the reference. In total the dataset contains 9 systems for the resynthesis task and 15 systems for the voice cloning task, where all systems are open-sourced as we excluded commercial, black-box models. In addition there are also natural samples from VCTK, serving as one system and also the reference samples. All samples have a sampling frequency of 16kHz.

Evaluation metrics
For the leaderboard, we will primarily be using and only showing on the leaderboard the utterance-level Spearman's rank correlation coefficient (UTT-SRCC) for both speaker and accent similarity.

However, in our final summary paper, as in previous challenges, we will report both system-level and utterance-level mean squared error (MSE), Linear Correlation Coefficient (LCC), SRCC, and Kendall Tau Rank Correlation (KTAU) are used.

Submission format
The prediction results should be put in a text file, and it MUST be named as answer.txt.

The format should look like:

system_id,utterance_id,wav_a_path,wav_b_path,pred_acc_sim,pred_spk_sim
sys003,utt010,wav/vmc2026-track3-sys003-utt010.wav,wav/vmc2026-track3-sys019-utt009.wav,0.7627164721488953,0.7627164721488953
sys012,utt166,wav/vmc2026-track3-sys012-utt166.wav,wav/vmc2026-track3-sys019-utt165.wav,0.4656715989112854,0.4656715989112854
The predicted score can be a floating point number and need not need to be an integer.
Note that it is okay to submit only pred_acc_sim or pred_spk_sim. It is of course okay to submit both. In other words, the submission can have either one of the following three headers:
system_id,utterance_id,wav_a_path,wav_b_path,pred_acc_sim
system_id,utterance_id,wav_a_path,wav_b_path,pred_spk_sim
system_id,utterance_id,wav_a_path,wav_b_path,pred_acc_sim,pred_spk_sim
Finally, compress the file with zip format and name it whatever you want. There is NO naming requirement for the zip file. To avoid generating extra folders, it is recommended to use the following command:

zip -j <any_name>.zip answer.txt
